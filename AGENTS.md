## GITHUB ACCESS

For routine GitHub work, use GitHub connector/API/MCP/CLI/repository tools first.

Do not open Chrome/browser to inspect repositories, files, commits, PRs, checks, reviews, comments, branches, workflows or logs.

Browser use is permitted only for genuinely UI-only actions requiring Rich's authenticated browser session, such as GitHub App installation/settings, organisation settings, OAuth approval or permissions that have no direct tool/API route.

If the required GitHub capability is unavailable, state exactly which tool/capability is missing before using the browser.

Opening Chrome for routine GitHub inspection is a workflow failure.
